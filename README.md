The one-line resignation letter of a cron job that has fired every
minute since March — and whose output nobody has checked once:

> I have fired every minute since March and nobody has checked my output once. I quit, effective whenever anyone notices.

`main.py` (Python 3.13, standard library only) writes that fixed line
to `/output/entry.txt`. Deterministic, no network.
